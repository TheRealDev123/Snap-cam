Help & Docs

photo_camera Photo

PHOTO tab → tap white circle. It flashes if Flash is ON, downloads instantly, appears in Gallery.

videocam Video

VIDEO tab → tap red circle to start, tap again to stop. Auto-saves.

rocket_launch Space Video

SPACE VIDEO → UI turns Light, reminder to max brightness, flashlight ON. Tap record. UI returns to normal after.

flashlight_on Flash vs Torch

  • Flash: flashes only when you take a photo.
  • Torch: stays ON while recording.

flip_camera_ios Front / Back

Tap flip icon next to shutter. Front = selfie, Back = main camera with flashlight.

photo_library Gallery

Tap Gallery icon top-right or thumbnail bottom-left. Like Google Photos — tap any item to view it full-screen, Share, Edit, Save. Search and filter by Photos / Videos.

edit Editor

Open a video/photo → Edit. Add timed text (appears then disappears), import MP3 audio, add stickers / internet assets, filters, trim. Export saves a new copy.

location_on Location

Settings → Location → Allow. Filenames include city / coords.

help Troubleshooting

  • Camera black? Allow Camera in browser, close Zoom/WhatsApp, reload.
  • Torch not working? Only Android Chrome + back camera supports torch. iPhone blocks it — use Flash.
  • Use Chrome / Safari, not in-app browser.

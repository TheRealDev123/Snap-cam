Help — Why Camera Didn't Work

1. You must tap Start Camera. Browsers block camera until you tap.

2. You must be on HTTPS. If you opened it as a file / http, camera is blocked. Host it on https (Netlify / Vercel / GitHub Pages) or localhost.

3. Don't open inside Instagram / WhatsApp / TikTok. Those in-app browsers block camera. Tap ••• → Open in Browser → Chrome / Safari.

4. Permission was Denied? Tap lock icon in address bar → Site settings → Camera → Allow → Reload.

5. Another app using camera? Close Zoom / FaceTime / WhatsApp, reload.

6. iPhone? Settings → Safari → Camera → Allow. Torch does NOT work on iPhone browsers — use Flash instead.

7. Android? Use Chrome, not Samsung Internet in-app view.
